# 학교 셔틀 편하게 타기 (DKU Shuttle)

단국대학교 천안캠퍼스 셔틀버스의 시간표, 오늘 운행 상황, 혼잡도를 한 화면에서 확인하는 웹앱입니다.

- **배포 사이트**: https://dku-shuttle-app.netlify.app
- **배포 사이트 (GitHub Pages)**: https://wjdtjdgml0415-ux.github.io/dku-shuttle/

## 만든 이유

| 현재 (As-Is) | 목표 (To-Be) |
|---|---|
| 셔틀 시간표를 직접 찾아봐야 함 | 시간표와 실제 운영 상황을 한 번에 확인 |
| 셔틀이 얼마나 붐비는지 알기 어려움 | 탑승 체크 정보로 남은 좌석 확인 |

## 시연용 계정

| 구분 | 아이디 | 비밀번호 |
|---|---|---|
| 학생 | `student` | `1234` |
| 관리자 | `admin` | `admin1234` |

회원가입으로 새 학생 계정을 만들 수도 있습니다.

## 주요 기능

### 학생
- **다음 셔틀 / 오늘 운행 정보**: 다음에 출발하는 셔틀과 회차별 운행·지연·취소 상태를 보여 줍니다.
- **탑승 체크와 혼잡도**: 탑승할 때 버튼을 한 번 누르면 회차별 남은 좌석과 혼잡도(여유·보통·혼잡)가 바뀝니다.
- **대기 등록**: 정류장에서 기다리는 중이라고 등록하면, 노선별 대기 인원과 대기 인원까지 태웠을 때 남는 좌석을 볼 수 있습니다.
- **지난 운행일 이용 현황**: 어제(또는 지난주 같은 요일)의 시간대별 탑승 인원을 보고 붐비는 시간을 미리 예상할 수 있습니다.
- **검색**: 시간대·노선으로 오늘 운행 회차를 찾습니다.
- **시간표**: 학교 공식 시간표를 요일별 운행 대수와 함께 보여 주고, 정류장별로 나눠 볼 수 있습니다.
- **학교 공지**: 축제 기간 연장 운행 같은 공지와 추가 회차를 보여 줍니다.
- **분실물**: 셔틀에서 잃어버리거나 주운 물건을 올리고 댓글을 달 수 있습니다.

### 관리자
- 시간표 회차 추가·삭제 (주말 운행 포함)
- 오늘의 운행 상태 변경 (정상·지연·취소)
- 공지 작성과 연장 운행 회차 등록
- 시간대별 이용자 수 통계
- 분실물 글 수정·삭제
- 회원 권한 관리
- 시연 도구 (요일·시각 바꾸기, 데이터 초기화)

## 사용 기술

- HTML, CSS, JavaScript (프레임워크 없이 `index.html` 파일 하나)
- 데이터 저장: 브라우저 `localStorage`
- 배포: Netlify, GitHub Pages

## 실행 방법

`index.html`을 브라우저로 열면 바로 실행됩니다. 별도 설치나 빌드는 필요 없습니다.

```bash
# 로컬 서버로 열 때
python3 -m http.server 5500
# http://localhost:5500 접속
```

## 참고 사항

- 시연용 과제라서 서버 없이 각 브라우저에 데이터를 저장합니다. 그래서 탑승 체크·분실물 같은 데이터는 다른 사람과 공유되지 않습니다.
- 처음 열면 시연용 예시 데이터(탑승 인원, 지연·취소, 분실물, 공지)가 자동으로 채워집니다.
- 비밀번호는 간단한 해시로만 저장하므로 실제 개인정보를 넣지 마세요.
